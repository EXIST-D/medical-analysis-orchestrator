# 医学统计方法选择规则

先识别研究设计，再识别结局类型，最后考虑相关结构、样本量、缺失模式和模型目的。方法推荐只能是候选方案，不能替代研究者对主要结局和因果问题的确认。

## 研究设计优先

| 设计/目标 | 首选方向 | 必查问题 |
|---|---|---|
| 横断面描述 | 描述性统计、患病率/比例及区间 | 抽样设计、权重、非应答 |
| 两组或多组比较 | 参数或非参数组间比较 | 独立性、分布、方差、单元格频数 |
| 观察性关联 | 多变量回归、分层/加权/匹配敏感性分析 | 混杂、共线性、事件数、缺失 |
| 预测 | 训练/验证、校准、区分度、决策曲线 | 数据泄漏、过拟合、外部验证 |
| 随访至事件 | Kaplan–Meier、Cox 或参数生存模型 | 时间起点、删失、比例风险、竞争风险 |
| 重复测量/聚类 | 混合模型或 GEE | 受试者 ID、时间、相关结构、失访 |
| 量表开发/验证 | 信度、EFA、CFA、测量不变性 | 条目方向、样本量、分布、理论结构 |
| 症状网络探索 | 网络估计、稳定性、桥接、组间比较 | 节点定义、正则化、Bootstrap、因果限制 |
| 条件依赖结构 | 贝叶斯网络或图模型 | 先验约束、方向可识别性、稳定性 |

## 按结局类型选择

| 结局 | 候选方法 | 关键诊断/限制 |
|---|---|---|
| 连续 | t/Welch/Mann–Whitney；ANOVA/Welch/Kruskal–Wallis；线性回归 | 分布、方差、残差、影响点、函数形式 |
| 二分类 | χ²/Fisher；Logistic 回归 | 小单元格、完全分离、事件数、校准 |
| 有序分类 | 秩和检验；有序 Logistic | 比例优势假设；不满足时部分比例优势模型 |
| 无序多分类 | χ²/Fisher；多项 Logistic | 类别稀疏、参照组、参数数量 |
| 计数 | Poisson 或负二项回归 | 过度离散、零膨胀、暴露时间 offset |
| 生存 | Kaplan–Meier、log-rank、Cox、参数模型 | 删失、比例风险、竞争风险、时间依赖效应 |
| 重复连续/分类 | LMM/GLMM 或 GEE | 随机效应结构、工作相关、缺失机制 |

## 组间检验规则

- 两独立组连续数据：近似正态且方差合理时用 t 检验；方差不齐用 Welch；分布严重偏斜或尺度为等级时考虑 Mann–Whitney。
- 三组及以上连续数据：条件满足时用 ANOVA；方差不齐用 Welch ANOVA；等级或严重偏态时考虑 Kruskal–Wallis。
- 分类数据：期望频数充分时用 χ²；稀疏列联表用 Fisher 或精确/Monte Carlo 方法。
- 配对或重复测量数据不得使用独立样本检验；改用配对检验、混合模型或 GEE。
- 多重比较必须预先说明校正策略和比较族。

## 扩展方法选择规则

- 缺失数据：先区分结构性缺失、特殊编码和随机缺失；只有研究者确认分析变量与插补模型后才运行 MICE。不得把第一个插补数据集当作正式结果，下游模型必须在每个插补数据集拟合并按 Rubin 规则合并。
- 分类结局：有序等级使用比例优势模型并审查该假设；无序三分类及以上使用多项 Logistic；不得仅根据数值编码猜测类别顺序。
- 计数结局：Poisson 必须审查离散比、零值和暴露量；过度离散时考虑负二项。零膨胀模型当前未实现，不得自动切换。
- 随访结局：无竞争事件时使用 Kaplan–Meier/Cox；竞争事件改变目标事件可观察概率时使用累积发生函数与 Fine–Gray。亚分布 HR 与原因别 HR 回答不同问题。
- 重复测量：需要个体特异效应或随机效应方差时使用混合模型；关注群体平均效应时使用 GEE。两者结果不得无条件互换。
- 诊断研究：确认金标准、阳性编码和阈值来源；同一样本选择 Youden 阈值并评估只属于表观性能。
- 倾向评分：先确认处理起点、基线混杂、estimand 和 positivity；只有加权后平衡与共同支持可接受时才解释加权效应，且仍需未测量混杂敏感性判断。
- 测量不变性：依次审查配置、度量、标量/阈值和严格不变性；拟合恶化时不得未经理论审查直接比较潜变量均值。
- SEM：模型语法必须由理论和时间顺序确认；拟合良好不能证明模型唯一或因果方向成立。
- 网络与贝叶斯网络：节点、相关类型、正则化/评分、黑白名单和 Bootstrap 次数必须预先确认；边、中心性和箭头不得表述为确定因果关系。

## 推荐时必须同时给出

1. 方法与研究问题的对应关系；
2. 输入变量角色及编码；
3. 适用条件与拟执行诊断；
4. 样本量/事件数是否支持；
5. 缺失值、异常值与多重比较处理；
6. 效应量和区间估计；
7. 至少一个合理替代方法；
8. 不能支持的解释，尤其是因果结论。

不得以“正态性检验 P 值大于 0.05”作为唯一方法选择依据；结合图形、样本量、稳健性和研究目的判断。
