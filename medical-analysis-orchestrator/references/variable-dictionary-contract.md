# 变量字典契约

变量字典每行对应一个原始变量，至少包含：

| 字段 | 含义 |
|---|---|
| `dataset` | 数据集或工作表 |
| `column_position` | 原始列序号 |
| `original_name` | 原始变量名 |
| `analysis_name` | 清洁数据中的唯一变量名 |
| `label` | 原文件变量标签或用户提供标签 |
| `source_dtype` | 原读取类型 |
| `inferred_type` | 连续、二分类、分类、日期时间或文本 |
| `candidate_roles` | ID、结局、分组、时间、事件或量表条目候选 |
| `unit` | 单位，未知时留空 |
| `missing_n`、`missing_pct` | 缺失情况 |
| `unique_n` | 非缺失唯一值数 |
| `value_labels` | 值标签摘要，不输出直接标识值 |
| `potential_identifier` | 是否可能为直接或准标识符 |
| `constant` | 是否为常量列 |
| `needs_confirmation` | 是否需要用户决定类型、角色或编码 |

变量角色只能标为候选。主要结局、事件水平、分组参照、分类变量参照、量表计分及单位必须由用户或正式数据字典确认。

变量名规范化只作用于清洁副本：

1. 去除首尾空白和不可见字符。
2. 空变量名改为 `unnamed_<列序号>`。
3. 重复变量名追加 `__2`、`__3`。
4. 保留中文、英文、数字和下划线。
5. 原始变量名与分析变量名的映射永久写入变量字典和清洗日志。
