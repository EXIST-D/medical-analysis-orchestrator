# 科学写作支持契约

本 Skill 的主体是医学数据分析编排，不自动代替研究者确定论文论点。科学写作支持只在 `reporting.manuscript_support.enabled: true` 且主张、证据和边界均经用户确认后启用。

## 不可虚构

不得编造或补齐：

- 样本量、效应量、区间、P 值或模型结果；
- 未执行的分析、实验、敏感性分析或验证；
- 机制、因果关系、文献、软件版本或数据来源；
- 未登记的局限、图表、补充材料或数据可用性信息。

缺少信息时保留明确占位或停止，不使用流畅文字掩盖证据缺口。

## 主张—证据—边界

论文级主张由用户在方案中确认：

```yaml
claims:
  - id: "claim_001"
    statement: "治疗组随时间的评分变化幅度更大。"
    evidence_refs:
      - "mixed-effects:01_固定效应"
    interpretation_level: "association"
    boundary: "仅适用于本研究设计、样本和模型设定。"
```

`evidence_refs` 使用稳定的 `module_id:table_id` 或 `module_id:figure_id`，不得直接引用未登记文件。执行后必须解析到同一 `run_id` 的统一结果对象。

解释层级只能是：

- `descriptive`
- `association`
- `prediction`
- `causal`

`causal` 必须有明确研究设计、目标量和识别依据；横断面、观察性关联、预测模型和网络方向不能自动升级为因果。

## 写作结构

- 结果：描述观察值、条件、效应量、区间、诊断和统计支持。
- 解释：说明结果可能意味着什么，并匹配证据强度。
- 边界：说明适用样本、设计、时间、模型和未解决的不确定性。
- 讨论：不得逐表重复结果；应处理替代解释和具体局限。
- 方法：必须让同行能够理解数据处理、分析变量、模型、缺失策略、多重校正、软件版本和随机种子。

不使用“采用常规方法”“进行了统计分析”“差异具有统计学意义”等不可复现表述。

## 语言强度

- 直接且充分证据：`显示`、`观察到`。
- 间接或趋势证据：`提示`、`与……一致`。
- 未验证机制：`可能`、`或可`。
- 禁止仅因 P 值显著使用“证明”“确定导致”“完全有效”。
- “未显著”不得写成“无效应”。

## 术语账本

术语账本合并：

- 变量名称与中文标签；
- 单位；
- 量表、结局、暴露和分组的规范名称；
- 用户确认的术语与缩写。

同一运行的 Word、表格、图形和论文支持制品必须复用规范名称，不为了语言变化随意更换医学术语。

## 生成制品

启用后生成：

```text
90_最终报告/02_主张证据边界表.csv
90_最终报告/03_统计方法与可复现性.md
90_最终报告/04_术语账本.yml
```

Word 报告增加“经确认的主张、证据与边界”章节。所有制品由确认方案和统一结果对象生成，不重新计算统计值。
