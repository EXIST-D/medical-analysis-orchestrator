# 学术结果表述与报告风格

本参考由本 Skill 独立制定，吸收可复核、证据优先、结论与边界匹配的通行学术写作经验；不复刻任何外部 Skill 的原文、模板或标识。

## 结果段

- 先写分析对象、样本定义、比较或模型条件，再写估计值、95% 置信区间和 P 值（如适用）。
- P 值不替代效应量、置信区间、模型诊断或临床语境。
- “未达到统计学显著性”不等于“没有效应”；应保留估计值与区间。
- 仅陈述统一结果对象中已登记的表、图、样本流、诊断和限制；不得补写未执行分析。

## 解释与讨论

- 解释必须与 `interpretation_level` 匹配：描述、关联、预测和因果不能互换。
- 关联、横断面网络、回归系数和内部性能指标不得写成确定因果、机制或外部可推广结论。
- 讨论不逐表复述结果，应说明替代解释、设计限制、样本边界、模型假设和需要验证的问题。

## 方法特异表述边界

- 多重插补：报告插补次数、变量、方法和合并规则；不得只报告某一个插补数据集的结果。
- 有序 Logistic：使用“比例优势比”，并说明比例优势假设是否得到审查；多项 Logistic 报告相对风险比及结局参照类别。
- 计数回归：使用发生率比并说明 offset、过度离散和零值审计。
- 生存分析：说明时间起点、事件、删失和随访尺度；HR 不写成绝对风险或概率变化。
- 竞争风险：区分累积发生函数、原因别风险和亚分布风险；subdistribution HR 不简称为普通 HR。
- GEE：写为群体平均效应；混合模型固定效应写为给定随机效应结构下的条件效应。
- 诊断准确性：区分 AUC、阈值性能和临床净获益；表观性能、内部验证与外部验证必须明确标注。
- 倾向评分：先报告共同支持、权重和协变量平衡，再报告 estimand 对应的加权效应；不得省略未测量混杂边界。
- 测量不变性：只有达到研究所需不变性层级后才比较相应潜变量参数；部分不变性必须披露释放约束。
- SEM：区分测量关系、结构路径和间接效应；观察数据路径不能自动表述为因果中介。
- 网络和贝叶斯网络：使用“条件关联”“边稳定性”或“结构学习”；箭头、中心性和桥接指标不得写成确定机制或干预靶点。

## 图、表与图注

- 表格使用清晰标题、变量定义、单位、样本量、统计量、区间和必要脚注。
- 图注说明分析单位、样本量定义、中心统计量、区间、检验、多重比较校正与 Source Data。
- 任何图、表或文字结论只能引用同一 run 的统一结果对象。

## 术语一致性

- 变量标签、单位、缩写与分组水平以术语账本为准。
- 中文叙述使用宋体规范名称；英文字母、数字、统计符号和软件包名保持精确拼写。
- 当信息不足时，报告证据缺口或停止生成主张，不用模糊措辞掩盖缺口。
