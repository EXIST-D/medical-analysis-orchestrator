# 报告与表格格式

报告器只读取同一运行目录下已验证的 `analysis_results.json`，不重新计算或手工转录统计值。

## Word

- A4，页边距 2.54 cm。
- 正文中文宋体，英文与数字 Times New Roman。
- 正文小四 12 pt，1.5 倍行距，首行缩进 2 字符。
- 标题仅使用黑色和必要字号层级，不使用装饰性底色。
- 表格为三线表；宽表只展示适合阅读的列和行，并指向完整 CSV/XLSX。
- 数值在 Word 中合理舍入；完整精度保留在机器可读结果。
- 图形居中并有简洁图题。
- 定量图图注同时写明样本定义、中心统计量、区间或误差、检验和多重校正。
- Word 使用可识别的 Heading 1/Heading 2 层级；表题和图题使用题注，不伪装为章节标题。
- 默认使用 [`medical-journal-v1` 表格呈现规范](medical-table-presentation.md)：表题置于表上方；首列左对齐、其余列居中；优先在同一单元格呈现效应估计与 95% CI；表内 P 值仅保留数值或 `<0.001`，正文才写 `P=` 前缀。CSV 继续保存未合并的机器可读字段。
- 每个进入正文的表或图之后，必须紧接一段证据说明：以自然叙述将图表编号嵌入句中（如“如表 2 所示”“进一步的事后比较显示（表 3）”“多变量模型结果见表 4”），先给出相应的样本量、比较对象、效应估计、95% CI 或 P 值（适用时），再用与设计匹配的描述/关联语言概括统计含义；不得只写“见表/图”，也不得使用“表中要点：”“图示解读：”等固定标签。
- 结果段只报告观察到的数值和比较，不扩展为机制或实践建议；讨论段只选择改变解释的关键证据，不逐图逐表复述数值。
- 结果陈述、解释和适用边界分开表达，不从显著性自动生成论文主张。
- 不在 Word 正文写入统计诊断、警告、研究局限性或可复现性信息；这些内容是运行级 Markdown 附件。

默认论文初稿顺序：

1. 摘要；
2. 关键词；
3. 引言（用户背景优先；缺省时使用无文献、无机制断言的中性背景）；
4. 资料与方法；
5. 结果（含样本概况、各确认模块的结果叙述、三线表与合适图形）；
6. 讨论（仅在研究设计和模型设定边界内解读结果，不生成因果结论）。

以下文件不属于 Word 论文初稿，必须单独保存在 `90_最终报告/`：

```text
06_统计诊断与警告.md
07_研究局限性.md
08_可复现性信息.md
```

启用 `manuscript_support` 时，可在论文初稿末尾增加“附录：经确认的主张、证据与边界”，并生成：

```text
02_主张证据边界表.csv
03_统计方法与可复现性.md
04_术语账本.yml
```

## XLSX

- 工作表隐藏网格线。
- 不使用填充色和多余颜色。
- 表头上方中粗线、表头下方细线、表尾中粗线，无竖线。
- 中文宋体，英文和数字 Times New Roman，正文 10.5 pt。
- 第一行表题，第三行为列名，冻结列名下方窗格。
- 脚注跨表格宽度合并显示。

CSV 不包含字体、边框或颜色；它是机器可读结果。

## 解释约束

- 优先报告效应量、区间和诊断，再报告 P 值。
- “未显著”不等于“无效应”。
- 关联、预测和因果问题必须区分。
- 随机试验的基线描述表不因惯例自动添加 P 值；观察性比较或用户确认的基线推断表需在分析方案中说明目的。
- 完整案例排除、多重比较、探索性分析和内部性能指标必须明确标注。
- 模型不收敛、事件稀少、完全分离或关键诊断失败时，不生成确定性结论。
- 只有用户确认且能解析到同一运行表或图的主张才能进入论文支持制品。
- 不编造分析、统计值、机制、因果关系、文献、软件版本或数据可用性信息。
