# 心理测量与因子分析规则

## 必须由用户确认

- 量表名称、所属条目、理论维度和反向计分规则；
- 条目是否为连续、近似连续或有序分类；
- EFA 因子数、提取方法和旋转方法；
- CFA 的 `lavaan` 模型语法、估计量、缺失策略与有序条目；
- 效标变量的临床含义和预期方向。

Skill 不根据列名自动反向计分、删除条目、合并维度或修改 CFA 模型。

## 信度与效度

- 每个量表至少 3 个条目，报告 Cronbach’s α、标准化 α、McDonald’s ω、条目—总分相关和删除条目后的 α。
- α 或 ω 阈值只作常规筛查，不能单独证明单维性、效度或可接受性。
- KMO 与 Bartlett 检验只评价因子分析适用性，不等于结构效度已经成立。
- 效标关联必须预先确认效标与方向；相关不构成预测效度或因果证据。
- 若完整案例少于配置阈值则拒绝；低于 100 例时明确提示不稳定风险。

## EFA

- 完整案例至少 50，且每条目至少 3 个案例；低于 100 或每条目少于 5 个案例时警告。
- 因子数必须写入确认方案；平行分析用于审计，不自动覆盖确认值。
- 默认最小残差法与斜交旋转；只有理论支持因子不相关时才考虑正交旋转。
- 输出全部载荷、共同度和独特性；不依据显著性或载荷阈值自动删条目。

## CFA

- 必须提供明确的 `lavaan` 模型语法，且模型收敛后才输出正式结果。
- 连续/近似连续条目可使用 MLR 与 FIML；有序条目通常需要适当有序估计量，不能与 FIML 组合。
- 报告 χ²、CFI、TLI、RMSEA 区间、SRMR、AIC、BIC、标准化载荷、组合信度与 AVE。
- 修改指数只作诊断审计，任何改模都需要理论依据、新方案指纹和重新确认。
- 同一数据反复 EFA/CFA 只能描述为探索；确认性结论优先使用独立样本或预先划分的验证样本。
