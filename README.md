# medical-analysis-orchestrator

通用医学数据分析编排 Skill。它遵循“先探查、再建议、经确认后执行”的原则，以 R 作为当前主要统计引擎，面向 CSV、Excel、DAT、SPSS、Stata、SAS、JSON 等常见医学和问卷数据。

当前版本：`0.0.1`

发布状态：Beta / 技术预览版

## 核心流程

```text
inspect → recommend → confirm → execute → report
```

- `inspect`：只读检查数据，生成数据清单、变量字典、质量报告和清洗候选。
- `recommend`：结合研究问题、研究设计与数据结构提出分析方法及限制。
- `confirm`：要求用户明确结局、变量角色、清洗规则、参照组和统计方案。
- `execute`：自动发现 R，按模块准备项目级依赖并执行已确认分析。
- `report`：验证统一结果对象，生成 CSV、三线表 XLSX、R 图形和 Word 报告。

未经确认时，不安装 R 包、不修改数据、不运行推断模型。

## 0.0.1 已支持的统计模块

- 描述性统计；
- 单因素组间比较；
- Pearson、Spearman 和 Kendall 相关分析；
- 多元线性回归；
- 二分类 Logistic 回归；
- 信度与效度分析；
- 探索性和验证性因子分析；
- 线性及二分类广义线性混合效应模型。

以下接口已经登记，但仍处于 `planned` 状态，不能生成正式分析结果：

- 扩展广义回归；
- GEE；
- 测量不变性；
- 生存分析；
- 网络分析；
- 贝叶斯网络。

## 安装

将仓库中的 `medical-analysis-orchestrator/` 目录复制到 Codex 或兼容 Agent 的 Skills 目录。

Skill 入口为：

```text
medical-analysis-orchestrator/SKILL.md
```

推荐运行环境：

- R `>= 4.3.0`；
- Python 3.11 或兼容版本；
- Python 编排依赖：`pandas`、`openpyxl`、`PyYAML`、`python-docx`、`pyreadstat`；
- R 包由确认后的模块按需安装。

## 依赖隔离

R 依赖默认安装到 Skill 项目级 `.r-library`，不修改系统 R Library。`.r-library` 是本机运行产物，不属于源码发布包，本仓库已通过文件白名单和 `.gitignore` 双重排除。

## 安全与统计约束

- 原始数据始终只读；
- 不为了显著性或预期方向修改真实数据；
- 不自动删除异常值、病例或重复值；
- 不自动改变问卷计分、反向计分或量表维度；
- 不擅自指定主要结局、事件水平、分组或参照组；
- 小样本、稀少事件、严重缺失、完全分离或不收敛时警告或拒绝复杂模型；
- 横断面关联、网络边和贝叶斯网络方向不解释为确定因果关系；
- 报告只消费同一 `run_id` 下经过验证的统一结果对象；
- 默认不在日志、manifest 或报告中输出逐行患者数据。

本项目不是患者数据匿名化工具，不构成医疗建议，也不能替代临床研究者、医学统计学家或伦理审查。

## 项目性质
